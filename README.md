# Калькулятор валют с лучшими курсами

Сайт: калькулятор + лучшие наличные курсы с адресами.
- Минск — select.by (USD, EUR, 100 RUB в BYN)
- Москва — ru.myfin.by, отделения банков (USD, EUR в RUB)

`scrape.py` каждые 30 минут запускается в GitHub Actions и обновляет `rates.json`.
Запуск вручную: вкладка Actions → «Обновить курсы» → Run workflow.
